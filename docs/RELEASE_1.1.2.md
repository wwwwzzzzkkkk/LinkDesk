# LinkDesk V1.1.2

## 更新

- 平板目标 API 26，最低兼容 API 24。系统支持的菜单、滑块和开关启用华为沉浸光感，自绘页面、键盘和扩展屏幕浮层使用协调的轻量玻璃视觉。
- 修复工作区切换引起的页面上下跳动，以及扩展屏幕进出时系统栏状态竞争。
- 独立光标最多保留四个在途包并优先发送最新坐标，改善快速移动卡顿；用户反馈“比刚才好很多”。
- 限制迟到回调引起的追赶帧突发，保持 2880 × 1920、原有码率及 HDR 能力。
- 保留 V1.1.1 的拇指分离键盘、Mac 功能键、液态玻璃调节、Delete 连续删除及 Caps Lock 输入源切换。

## 验证与限制

HarmonyOS 7 平板页面加载后系统报告沉浸光感可用；已检查工作台、PDF、白板、投屏、扩展屏幕和键盘的主要外观及页面切换。API 24 设备和全部横竖屏组合尚未实机验收。详见[光感说明](IMMERSIVE_LIGHT_UI.md)。

HDR、144 fps 目标的动态短测中，筛选出的 25 个活跃一秒样本解码提交为 82–116 fps，中位数 104；平板系统实际报告 120 Hz。场景和负载不受控，不能以此断言改动提升帧率，也不能保证稳定 120／144 fps。光标确认耗时不包含实际显示，物理端到端延迟与长期热稳定仍待测。详见[光标与帧节奏](CURSOR_FRAME_STABILITY.md)。

公开发行提供 Apple Silicon Mac 安装包和双端源码。鸿蒙个人调试签名绑定设备，需自行在 DevEco Studio 配置签名构建；Mac 包使用固定开发证书，尚未经过 Apple Developer ID 公证。首次使用仍需按照系统提示授权。
