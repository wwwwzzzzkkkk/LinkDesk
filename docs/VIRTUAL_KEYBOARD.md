# 平板虚拟键盘 · V1.1.1

2026-10-27。V1.1.0新增，V1.1.1改进分离布局、液态玻璃与按键行为；当前发行方式及检查见[发布记录](RELEASE_1.1.1.md)。

## 使用

1. 两端打开LinkDesk。首次可用USB自动配对；纯无线首次配对可重新扫描Mac“连接与配对”的二维码。旧六位房间号不会自动获得控制电脑的权限。
2. Mac需要允许LinkDesk发送按键。本机macOS 27中的入口是“系统设置 → 隐私与安全 → 设备控制和数据访问”；旧版系统为“辅助功能”。应用侧栏提供授权入口，沿用原签名与应用标识。
3. 扩展屏幕的悬浮面板点击“键盘”；工作台也有“虚拟键盘”。键盘连接独立于视频模式，未启动扩展屏幕时仍可使用。
4. 在Mac上先点选要输入的应用和文本框。平板按键会发送到Mac当前前台输入位置，不会自动选择某个应用、搜索框或文稿。
5. 布局菜单提供“全宽停靠”“双手分离”“全屏键盘”“悬浮紧凑”。优先完善全宽和分离；分离字母区采用QWERT／ASDFG／ZXCV与YUIOP／GHJKL／VBNM，中排内移、G／V两侧重复。Mac功能键围绕字母区排列，左右各有空格与Command；顶端保留数字行，左侧“符号”菜单切换数字／符号，fn展开方向键，中间留白。
6. 左侧液态玻璃“调节”卡片可分别设置键宽、键高和离底高度。尺寸按布局、横竖屏分别保存；宽度上限随当前屏幕与数字区自动计算，避免拖动到无效范围。全屏模式允许更高的按键；分离／停靠键盘可上下拖动左侧握柄，紧凑悬浮还可左右移动；位置受屏幕边界限制并保存。
7. 字母、数字、标点、空格、Return、向后删除、方向键、Tab直接发送。fn展开Esc、F1–F12及导航／媒体键；调节面板可切换F13–F20。支持Home／End／Page Up／Page Down／向前删除、Caps Lock（短按切换Mac输入源并清除虚拟大写锁定；长按或fn区“⇪ ABC”切换本键盘大写锁定，长按不会同时切换输入源）、数字小键盘以及ANSI／ISO／JIS手动配置。左侧“中 / 英”菜单显示Mac实际输入法，点击该项可切换Mac已启用的输入源；物理键码由Mac当前输入法解释，键帽目前保留所选键盘的标示，不自动跟随Dvorak等自定义字符布局。
8. Shift／Control／Option／Command支持三种方式：点按供下一键使用，按住与另一手组合，双击锁定。选中状态会高亮；“释放修饰键”可统一解除。支持多种修饰键叠加，例如⌘⇧Z。单次组合会发送真实修饰键按下和抬起，持续组合由有期限的心跳续租。
9. 按下时立即变色并轻微下沉／缩小，抬起后恢复；减少动态效果开启时仅保留颜色。可在调节面板开启触感反馈，设备不支持时退回视觉反馈。普通字母、空格、删除及方向键在按住约420毫秒后每70毫秒连发；分离字母区无修饰键时长按约350毫秒输入上标数字／符号，短按在松手时提交字母，带修饰键时立即输入组合。删除松手后取消定时器和待发送重复；有修饰键时仅删除和方向键连发，避免反复执行应用快捷键。
10. 左侧“中 / 英 → 中文 / 手写”调用平板系统输入法，候选文字确认后点“发送”。中文、表情等通过Unicode发送，不传递未确认的预编辑内容。切换到系统输入法时收起字母区；关闭键盘清空草稿。
11. 在“调节 → 更多选项”查看实际连接状态，选择USB优先或Wi-Fi优先。优先通道不可用时尝试已配对的另一通道；常态不显示连接横条。

两端在同一可达局域网时可通过Wi-Fi使用键盘。USB首次配对会记住Mac当前网络地址；现有扫码／发现连接也可更新地址。Mac地址变化后可重新通过应用发现或USB更新；不支持通过互联网中继控制键盘。

## 下拉全局入口

“调节 → 更多选项 → 启用下拉入口”请求通知权限，开启后在连接就绪时发布“虚拟键盘”通知。从平板桌面或其他应用下拉通知栏点击，可打开LinkDesk键盘；输入前重新验证连接及Mac授权。

这是**通知栏入口**，不是系统控制中心的自定义快捷开关。当前SDK没有找到适用于该平板普通应用的控制中心开关注册接口；PC状态栏／Quick Bar接口不适用于此设备。没有冒用系统权限或将应用内按钮称为系统快捷开关。

点击通知会打开LinkDesk窗口，不是在任意平板应用上叠加系统全局悬浮窗。后台进程被系统暂停后，通知状态可能暂时滞后；打开后必须重新验证，断线不会允许输入。前台检测到断线后禁用键盘并撤下通知；没有用音频录制等不相关后台模式保持进程。

## 连接与输入保护

- 键盘复用3210连接入口，独立于视频帧、解码与光标通道，不改变2880 × 1920画质设置。
- 首次USB配对仅允许经回环连接、固定Host及原生请求获取随机256-bit配对密钥；拒绝浏览器Origin／Fetch请求及局域网直接获取密钥。
- 无线二维码通过URL片段携带配对信息，片段不进入HTTP请求路径。请勿公开配对二维码或将其加入发行截图。
- 键盘内容及确认使用AES-256-GCM，绑定会话和传输方向，随机nonce、严格递增序号。Mac只接受经过本机认证的主机WebSocket，网络请求不能直接调用按键事件。
- 按键具有约1秒有效期；队列最多24条，关闭、后台、断线及会话变化清空待发输入，不跨重连补发。Mac再次检查授权、安全输入状态与有效期；安全输入开启时暂停发送。
- 每次普通按键均发送完整按下／抬起；持续修饰键由认证会话拥有，每250毫秒续租，丢失续租最多约1.5秒后释放。收起、切换布局、后台、断开主机或授权失效均清理；Mac在拖动等事件跟踪期间也检查租期。服务端检测重复／过期命令时通知Mac释放相应会话，其他会话的零状态不能释放当前拥有者。
- 确认表示Mac事件已提交，不保证每个应用都会处理；安全输入、专用游戏或特殊输入框可能拒绝合成事件。媒体键由系统决定行为；fn在此用于展开键区，未伪装成硬件Globe／Fn键。
- Mac配对密钥保存在应用支持目录的私有子目录（0700）及文件（0600），不写入仓库或日志；平板保存在应用私有数据中。应用不读取系统剪贴板来发送文字，不记录输入内容。专用键盘测试标志仅记录权限、前台状态、按键代码、重复标识和错误码，不记录提交的文本；日常模式不启用此日志。

## 改动位置

- Mac：`KeyboardHost.swift`处理授权、Mac键码、输入源、按键与Unicode，`KeyboardModifierLease.swift`负责有期限的修饰键；`LocalRelayLauncher.swift`启动主机连接；侧栏提供授权状态，原配对二维码附加键盘配对信息。
- 中继：`InkBridge/keyboard-relay.mjs`独立实现认证、加密、序号、限流、过期及Mac提交确认；构建脚本将模块一起打包。
- 平板：`ets/keyboard/KeyboardClient.ets`、`KeyboardPanel.ets`、`KeyboardKey.ets`、`KeyboardLayout.ets`、`KeyboardNotification.ets`；`Index.ets`提供应用级键盘层，`DesktopReceiver.ets`提供扩展屏幕入口，Ability处理后台清理及通知调用。
- 视觉与文案：`design-tokens.json`／`strings.json`生成双端资源；键盘面板已加入原生界面检查。

## 微信输入法候选栏（V1.2.0）

平板虚拟键盘保持可见时，在 Mac 选择微信输入法并用虚拟键盘输入拼音，键盘上方会显示微信输入法辅助功能窗口暴露的候选词；点击候选项向 Mac 发送对应数字选词。候选数据由现有加密键盘通道传输，仅保存在内存，不写入日志或文件；关闭键盘、连接断开或安全输入时不再显示。当前只适配 Mac 微信输入法，其他输入法、自绘候选窗口及单候选场景未保证支持。

候选更新时保留容器并原位替换内容；短暂空结果延迟收起，正在等待新候选时忽略候选点击，避免选到旧数据。2026-10-29 双端真机：用户确认候选一致、点击选词正确；防闪烁更新后反馈“更新自然，选词正确”。
