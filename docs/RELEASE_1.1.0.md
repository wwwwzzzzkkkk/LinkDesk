# LinkDesk V1.1.0

2026-10-26。Mac与HarmonyOS统一为1.1.0；Mac构建号110000，HarmonyOS版本码1010000。

## 新增功能

- 平板Mac虚拟键盘：USB／同一局域网Wi-Fi，实际通道显示与优先方式切换，独立于视频。
- 全宽停靠、双手分离、大按键全屏、可拖动紧凑悬浮四种形态；可调键宽／键高，按布局及横竖屏分别保存。
- 按压变色、轻微缩小和下沉反馈；减少动态效果时保留颜色，可选触感按设备能力提供。
- Command、Option、Control、Shift支持点按一次、按住组合、双击锁定；F1–F20、导航、方向、前后删除、数字区与ANSI／ISO／JIS手动布局。
- Mac实际输入源显示与切换，Caps短按遵循Mac设置，长按／fn区按钮锁定本键盘大写；中文／手写／表情通过平板输入法确认后发送。
- 连接就绪时通知栏可调出键盘；点击会进入LinkDesk，不是控制中心系统开关或跨应用悬浮窗。
- 认证配对、AES-256-GCM双向确认、序号和有效期检查；后台与收起清理待发输入，修饰键丢失续租约1.5秒后释放。
- 修复副符号重叠、长按结束后的重复点击，保留2880×1920扩展桌面、独立光标、HDR10、麦克风同步、PDF、白板与投屏。

## 已有功能真机验收

以下来自本次开发阶段的Mac mini与MatePad，发布构建检查单独列出，不作为新的高刷或延迟基准。

- USB及Wi-Fi键盘实际向Mac文本框输入，Wi-Fi测试保留USB用于HDC自动化，未进行物理拔线测试。
- 在系统“文本编辑”中验证Command全选、Option整词删除、Control行首导航及向前删除；验证Shift点按与锁定／解除、Caps锁定与解除。
- 键宽56→71后左右键区实际变宽，覆盖安装后尺寸保留；全宽／全屏／悬浮64键及JIS数字区87键通过屏幕边界检查。
- 悬浮键盘拖动成功；已采集真实按下反馈画面；长按结束后修饰键恢复未选中，Caps长按锁定不会因抬手重复点击而取消。
- 扩展屏幕工作中保持2880×1920，键盘仍可通过USB使用。

## 发布构建检查

- 双端版本一致，Mac使用原固定证书，个人绑定设备HAP签名构建；保留原应用标识，不重置授权数据库。
- 45项协议／绘制回归，PDF坐标、白板像素、麦克风、管线预算、帧节奏、光标、HDR流格式及修饰键租期／释放原生回归。
- 共享界面生成文件与12个原生界面文件文案／样式检查，Mac严格签名及发行包内容检查。
- 发布包不捆绑HDC／华为SDK、私钥、口令、设备Profile或运行时配对密钥。

- 发布构建已覆盖安装两端，设备版本核对为1.1.0／110000（Mac）和1.1.0／1010000（HarmonyOS）；Mac正常LaunchServices启动、退出重开后重新连接2880×1920扩展桌面，平板分离键盘保留，USB键盘状态就绪，原录屏与按键授权仍有效。

## 分发与使用

Mac发行包包含应用、三个现有音频驱动、签名保护安装脚本、许可证和对应源码，附SHA-256校验文件。使用原固定开发证书，尚未Apple Developer ID公证。Homebrew Cask同步到本版。

HarmonyOS公开对应源码；个人调试签名HAP仅用于绑定设备本地升级，不公开上传。其他设备在DevEco Studio中自行配置签名。双端需要一起更新才能使用新版键盘。

Mac首次发送按键需要系统授权：本机macOS 27入口为“隐私与安全 → 设备控制和数据访问”，旧版为“辅助功能”。首次可通过USB配对或重新扫描Mac二维码；旧六位房间号本身不会授予键盘控制权限。

## 仍待验证与支持边界

- 双手同时触摸组合键、持续长按连发节奏、物理旋转及触感主观验收仍待补充。所有应用及系统输入法／自定义键位兼容性未穷尽测试。
- Mac前台应用接收按键；安全输入开启时暂停。fn用于展开键区，未实现硬件Globe／Fn按住语义；自定义Dvorak等键帽不会自动映射。
- 通知入口会打开LinkDesk；不提供跨应用全局悬浮窗。后台进程可能被系统暂停，重新打开后验证连接。
- 本版未重做120／144fps、高刷热稳定或输入到光子的物理延迟基准；此前性能与限制见[V1.0.0记录](RELEASE_1.0.0.md)。
- HDR10不等于原生杜比视界；本版不包含Mac系统摄像头扩展。
