## 未验证

- 系统分屏、自由窗口、多窗口拖拽与极窄窗口的完整真机流程。布局已按可用宽度与方向处理，但本轮未进入系统分屏验证。
- 实体笔的压力、悬停精度、掌触防误触、橡皮压力切换、双指缩放和平移；更改的是周围控件，不将源码不变等同于实测。
- “减少动态效果”开关在前台与后台切换的真机视觉效果，以及系统字体大字号／英文长文案的完整布局。
- 真实桌面环境下 Mac 系统合成的液态玻璃视觉、旧 macOS 材质降级、不同桌面背景与显示器缩放。
- 视频画质、长时间收发、音画同步、扬声器／麦克风、频繁模式切换与 USB/Wi-Fi 并发切换。
- 错误分支、权限拒绝、Wi-Fi主题同步、两端同时修改主题的完整组合。统一错误态已实现，但没有穷举模拟全部异常。
- LiveView 权益与外部华为笔记往返，本轮没有进行平台权益或外部应用验收。
- 既往协议／坐标／白板／麦克风全套回归未因本次 UI 改动再次重复运行；历史结果保留在整合说明中，不算本轮新增验证。
