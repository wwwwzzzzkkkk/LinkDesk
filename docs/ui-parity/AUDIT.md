# UI 审计（改动前）

基线：当前 PR 的 LinkDesk 0.7.0，2026-10-18。以下数值来自源码；旧横屏截图仅用于辅助阅读。没有把源码推断写成真机结果。

## 设计系统现状

Mac 已有 `NativeSearchGlassModifier`、`WindowLiquidGlassConfigurator` 和 `accessibilityReduceMotion`；平板已有 `backgroundEffect`、收起动画和 `isAnimationReduceEnabledSync()`。当前分支没有独立设计／动效令牌、公共 PageHeader／SettingRow／EmptyState 或 ConnectionState 类型。保留现有原生材质，以本次数据源补齐公共契约。

| 项目 | Mac 值 | 平板值 | 应统一 | 理由 |
| --- | --- | --- | --- | --- |

状态应从已有 relay transport、Mac engine 和平板原生 stats 推导，不扩充协议。连接本机中继不等于平板已连；设备就绪不等于视频已显示。Wi-Fi 活动说明保留传输方式，不写成 USB。物理未配对时平板无法知道 Mac 的 USB 枚举结果，必须显示本地可观察状态；不伪造跨端同步。

## 自适应布局审计（源码分析）

- 横屏：Index 1000vp最大宽度、两列卡片；现有首页可见。InkWorkspace 顶部46vp同时排列品牌、模式、配对码、状态、回传、外观、投屏、收起，存在遮挡风险。底部若干按钮仅34–38vp。
- 竖屏：EntryAbility 使用 AUTO_ROTATION_LANDSCAPE，当前未开放竖屏。若仅解锁旋转，配对页不滚动、头部横排和二级菜单固定360/380/390vp会挤出可用空间。
- 分屏：manifest没有配置禁止分屏，但是否可进入由设备／系统决定，本次审计未真机确认。首页只在700vp以下变单列；其他页面没有按可用窗口宽度调整。工具弹层、二维码／表单、长状态文案可能溢出。
- 接收画面按1.5宽高比fit，保持不拉伸；系统栏显隐需单独管理，不能靠覆盖蓝色背景处理。

设计决定：宽度≥840vp使用侧栏，窄窗口使用五项底部导航；不按设备型号判断。底部导航避免压缩PDF横向空间。工具栏横向滚动、弹层限于可用宽度，表单可纵向滚动。视频工作中隐藏导航及系统栏，点按显示退出控制。

## 官方依据与边界

华为[触控热区规则](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-v5/ide_touch-target-size-V5)：主要交互元素推荐48vp×48vp，不小于40vp×40vp。本项目选48vp。API使用前继续核对当前官方参考与本机SDK声明；接口版本、联网查询失败与真机未验证分别记入API-NOTES.md。

笔迹坐标、压感、笔粗细数值、显示帧率／分辨率、协议字段、存储key与格式均为功能数据，不能为消除UI字面量而改写。设计令牌只替换视觉值；颜色选项进入独立inkPalette保持原始值。主题同步与pending持久化流程保持不动。
