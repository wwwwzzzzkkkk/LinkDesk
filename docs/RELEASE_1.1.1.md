# LinkDesk V1.1.1

2026-10-27。Mac与HarmonyOS统一为1.1.1；Mac构建号110100，HarmonyOS版本码1010001。两端需一起升级。

## 本版改进

- **拇指分离布局**：字母区按平板握持习惯排列，左QWERT／ASDFG／ZXCV、右YUIOP／GHJKL／VBNM，中排内移、G／V两侧重复。Tab、Caps Lock、Control、fn等Mac功能键加在Mac对应行：Tab在Q左侧、Caps在A左侧、Shift在Z左侧，fn／Control／Option／Command在左下角；右侧保留Return、删除与倒T方向键。
- **数字与符号**：顶端保留数字行，左侧“符号”菜单切换字母／数字／符号页，字母上标可长按输入；带修饰键时立即输入组合。fn展开完整功能／导航／方向／媒体键，支持F1–F20及ANSI／ISO／JIS额外键。
- **液态玻璃调节**：圆角键帽、局部背景模糊、细高光与柔和阴影；调节面板改为左侧紧凑玻璃浮层。键宽／键高并排，离底高度单独调节，其他选项收纳在菜单中。
- **更少遮挡**：输入法入口放在左侧控制胶囊，中央留白；去掉整条常驻USB连接状态栏。分离／停靠可上下拖动，紧凑悬浮还可左右移动，尺寸和位置按布局、横竖屏保存。
- **Delete连续删除**：持续按住约420毫秒后，每70毫秒发送一次完整按键；松手停止定时器并丢弃待发重复，减少慢连接下的补删。Mac不再将独立消息伪装为实体键保持按下的系统重复事件。
- **Caps Lock中英文切换**：短按切换Mac输入源；长按单独切换本虚拟键盘的大写锁定，不同时触发短按，不改变实体键盘的持久锁定状态。

保持2880×1920扩展画质、独立光标、HDR10、麦克风双向同步、PDF、白板、投屏及通知栏键盘入口。

## 验证

- 53项协议／绘制／键盘自动测试通过，覆盖参考字母排列、页面缓存身份、Mac按键覆盖、长按时序、Caps短按／长按互斥，以及松手取消重复队列。
- PDF坐标、白板像素、麦克风、管线预算、帧节奏、光标、HDR流格式及修饰键租期／释放原生回归通过；双端构建、共享界面资源与原生样式检查通过。
- 真机长按Delete：62字符测试文本剩32字符，松手停止删除；Caps短按实测ABC → 微信输入法 → ABC，长按高亮与解除通过。
- 分离布局、数字／符号切换、fn展开、上下移动、隐藏恢复、位置记忆与玻璃调节界面进行真机检查。
- 原固定签名及应用标识保留，不重置录屏或输入授权。

## 分发

Mac包包含Apple Silicon应用、三个现有音频驱动、签名保护安装脚本、许可证与对应源码，附SHA-256校验文件；Homebrew Cask同步到本版。继续使用原固定开发证书，尚未Apple Developer ID公证。

HarmonyOS公开对应源码；个人调试签名HAP与设备绑定，仅安装到已绑定平板，不公开上传。其他设备需在DevEco Studio自行配置签名。

## 支持边界

- 真正双指同时按住修饰键的手感、触感强度、物理旋转及全部第三方应用／自定义输入法尚未穷尽验收。
- 分离模式的字母长按用于上标，普通全宽键盘保留字母连发；fn用于展开键区，未实现硬件Globe／Fn按住语义。
- 通知入口会进入LinkDesk，不提供跨应用系统悬浮窗。安全输入开启时暂停发送。
- 本版未重做120／144fps、长期热稳定或物理端到端延迟基准；HDR10不代表原生杜比视界，不包含系统摄像头扩展。
- 仍存在既有SDK兼容／弃用提示和测试中的fabsf警告，不影响本轮构建与回归结果。
