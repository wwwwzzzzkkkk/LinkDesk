# LinkDesk V1.2.0

## 本次更新

- USB 扩展屏幕新增直接触摸：点按、双击、窗口拖动、长按右键、单指／双指滚动、惯性缓冲与文字选择；智能／滚动／选字模式可切换。
- 双击可识别的 Mac 输入框自动打开平板虚拟键盘；键盘按钮在重连时仍可打开并刷新状态。
- Mac 微信输入法候选词同步至键盘上方，可点击选词。候选内容原位更新，短暂空结果不立即收起，等待更新期间阻止旧候选被点击。
- 保留分离／停靠键盘、液态玻璃、快捷键与原有 2880 × 1920、HDR10 和独立光标能力。

## 验证与限制

Mac mini 与 MatePad 真机验证了触摸位置、窗口拖动、长按右键、双指滚动及文字选择；用户反馈优化后的单指滚动明显更顺滑。双击输入框自动弹出键盘并输入成功；微信输入法候选词一致、点击选词正确，防闪烁更新自然。详见[触摸控制](TOUCH_CONTROL.md)和[虚拟键盘](VIRTUAL_KEYBOARD.md)。

扩展屏幕通过 USB，虚拟键盘支持 USB／Wi-Fi。触摸使用 Mac 鼠标和滚动事件，不是系统级原生多指触摸；捏合、压感和系统多指手势尚未实现。其他 Mac 输入法与单候选场景尚未保证支持；部分自绘输入框不能自动识别。未完成物理端到端延迟、长期热稳定和全部应用兼容性测量，不能保证稳定 120／144 fps。

公开发行包括 Apple Silicon Mac 安装包和双端源码；鸿蒙个人调试签名绑定设备，需自行在 DevEco Studio 配置签名。Mac 包使用固定开发证书，尚未经过 Apple Developer ID 公证。
