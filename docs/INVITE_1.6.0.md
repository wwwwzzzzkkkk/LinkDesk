# LinkDesk 1.6.0 邀请测试 · Beta 1

适用于 Apple Silicon Mac 和支持的 HarmonyOS MatePad。Mac 端从 GitHub Releases 下载并安装。

## 首次连接

1. 在 Mac 和 MatePad 打开 LinkDesk，并接入同一个 Wi-Fi。
2. 在 Mac 点「连接与配对」，选择「Wi-Fi」，在 MatePad 用 LinkDesk 扫描 Mac 显示的二维码。二维码有效期两分钟，每个二维码可完成一次新配对。
3. 配对后可从访达的「共享 → 发送到 LinkDesk 平板」发文件。在 MatePad 的系统分享菜单可点「LinkDesk · 发送到 Mac」。Wi-Fi 文件收发使用设备凭证认证，文件内容和文件名在传输中加密。
4. 在 Mac 的配对窗口可移除 Wi-Fi 文件授权。再次通过 Wi-Fi 收发时，平板需重新扫码。

「自动选择」「Wi-Fi」「USB」仍可选。自动选择可优先使用可用的 USB 连接。扩展屏幕、实时白板、PDF 批注、平板投屏、键盘和麦克风的入口继续提供。扩展屏幕和平板投屏沿用已有 USB 调试链路。Wi-Fi 配对和系统文件收发独立于这条调试链路。

## PDF 批注往返

1. 在访达选中 PDF，点「共享 → 发送到 LinkDesk 平板」。
2. 在 MatePad 的「文件传送」选择该 PDF，点「用华为笔记批注」。
3. 完成批注后，在华为笔记选择「分享为 PDF → LinkDesk · 发送到 Mac → 回传批注副本」。
4. 在 Mac 的保存窗口选择位置，保存带「批注」后缀的新文件。Mac 上的原 PDF 保留。

本版在 Mac mini 与 MatePad 真机跑通了上述流程。测试通过 Wi-Fi 配对和往返传送 PDF，USB 调试仅用于安装和操作测试设备。Mac 收件记录显示 Wi-Fi，回传件含实际笔迹，原文件的 SHA-256 校验一致。自动检查还覆盖了二维码重复使用、错误凭证、篡改数据、撤销授权及 USB 收件。

## 安装与分发

- Mac 包沿用原 LinkDesk 安装标识和开发签名，当前测试包尚无 Apple Developer ID 公证。下载压缩包后解压，使用随包的安装脚本或从测试目录启动。
- Wi-Fi 文件功能建议两端一起更新。旧版本在升级后可用新二维码完成授权。
- 平板端使用设备绑定的测试签名验证。华为应用市场邀请分发需另行准备发布签名和测试名单，个人签名包仍由各测试设备的签名范围约束。
- 本次安全改动覆盖 Wi-Fi 配对和系统文件传送。原有实时画布和屏幕传输使用各自的协议。
