# LinkDesk V1.4.0

## 本次更新

- **扩展屏幕手写笔**：平板区分手指和笔，传递位置、压力和倾斜；Mac 使用数位笔点及匹配的设备进入／离开事件。普通应用仍可接收鼠标兼容事件，支持数位笔事件的应用可以读取压感。
- **笔与手指一致的智能操作**：笔在智能模式下可单指滚动、拖动、长按右键及双击受支持输入框／空白处显示或收起键盘；在选字模式可拖选文字。目标识别使用已有无障碍判断与方向回退，绘画仍可使用压力。
- **手写采样与流畅度**：每帧笔历史采样合并为受限批次，经现有独立 AES-GCM 连接发送，校验坐标、压力、数量与序号。按下、抬起和取消保持顺序；背压时仅保留最近有限采样，断连或权限失效释放按住状态。
- **高清画面**：高帧率 HEVC 的采集缓冲由 6 增至 8，高帧率目标码率从每目标帧 45 万增至 65 万比特／秒；保持 2880 × 1920、HDR10 和原有低延迟防积压。高码率和额外缓冲可能提高带宽与内存占用，不保证帧率锁定。

## 真机验证

- Mac 与 MatePad 的测试画布收到了真实数位笔事件，用户确认轻重改变线宽。补充设备感应事件后，用户确认 Mac 无边记钢笔压感有效。
- 用户确认笔在智能模式滚动网页、双击输入框弹出与双击空白收起键盘、选字、长按右键均正常；手指滚动正常，智能模式下的无边记压感仍正常。
- 针对间歇卡顿的诊断版中，用户反馈手指和笔滑动流畅，重连后立即操作也不卡。平板采样统计中，手指连续移动约 120 次／秒、待发送等待通常 1–2 毫秒；笔的历史采样更多，部分先前会被合并。这些数值是有限测试记录，不是端到端延迟保证。
- 最终批量传输版用户确认手指与笔滑动均流畅、压感正常。双端构建、65 项协议测试、笔事件和原生回归检查通过；HDR10 平板输出核验为 10-bit PQ。Mac 保留固定签名身份，平板通过原设备的个人调试签名覆盖安装。

## 限制与安装

- 不同 Mac 应用对合成数位笔事件的支持不同：已验证测试画布和无边记，其他绘画软件、笔型号、所有界面及系统版本未逐一验证。应用没有暴露足够无障碍信息时可能需要切换智能／滚动／选字模式。
- 笔接触期间忽略手指触点以减少误触；笔和手指同时执行双指手势暂不支持。悬停、侧键、橡皮擦、所有压感级数及精确物理端到端延迟尚未完整验收。
- 实际帧率随内容、负载、显示和解码能力变化；该平板实测约 120 Hz，目标 144 fps 不是持续达标保证。高码率需要合适的连接带宽；长期热稳定尚未完整测试。
- 公开发行包括 Apple Silicon Mac 安装包、校验文件和双端源码。鸿蒙个人调试签名绑定设备，不公开个人签名 HAP；请在 DevEco Studio 自行签名安装。Mac 包使用固定开发证书，尚未经 Apple Developer ID 公证。建议双端一起升级。
