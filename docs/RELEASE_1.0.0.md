# LinkDesk V1.0.0

2026-10-26。Mac 与 HarmonyOS 版本统一为1.0.0；Mac构建号100000，HarmonyOS版本码1000000。

## 本版功能

- 保持2880 × 1920高清扩展桌面，新增独立USB光标通道，改善鼠标连接Mac并移入平板时的跟手感。视频断线、光标通道断线分别处理，必要时恢复视频内光标。
- 优化高帧率拖动时的防积压策略，保留有限在途帧、过期原始帧淘汰及原高清码率，不以降低分辨率换取帧率。
- 新增默认关闭的HDR10 10-bit选项，覆盖能力协商、真实HDR采集、HEVC Main10编码及平板P010／PQ显示验证。
- 修复平板底部手势白条的沉浸显示，返回工作台恢复系统栏。
- 保留紧凑玻璃悬浮面板：实时状态、拖动、弹簧隐藏、胶囊恢复、返回工作台和重新连接。
- Mac／平板任一端设置麦克风后自动同步；画质／帧率切换引起的重连保留开启意图。首次录音仍需要平板系统授权。
- 完整保留PDF批注、无限白板、平板投屏、华为笔记往返及双端外观同步。

## 已有真机验证

以下性能来自2026-10-25同一项目的本地测试，已纳入本版；发布构建检查单独记录，不冒充重新完成的性能基准。

| 项目 | 结果 |
| --- | --- |
| 独立光标 | 用户反馈“明显更跟手”；USB接收确认均值约4.8–5.9 ms，不含UI提交及屏幕扫描 |
| 高清拖动 | 用户反馈“帧率更高，拖动也跟手”；人手拖动样本大多114–131 fps，存在约93 fps下探 |
| SDR120 | 自动快速窗口运动113–121 fps，中位数118.5；采集至解码确认批次均值中位数38.3 ms |
| SDR144 | 自动窗口运动短窗口中位数127.5 fps，尚未持续达标 |
| HDR10 | Main10、10-bit P010与BT.2020 PQ信号验证成功；用户确认“亮部有层次，桌面颜色正常” |
| HDR帧率 | 60目标约57–61；120目标约86–90；144目标稳定段约75–79，仍有更低波动 |
| 沉浸界面 | 扩展屏幕底部白条隐藏，返回工作台恢复，再进入可再次隐藏 |

## 分发方式

Mac公开发行包包含应用、三个音频驱动、签名保护安装脚本、许可证和对应源码；另提供SHA-256校验文件。沿用原固定开发证书，尚未Apple Developer ID公证。公开包不捆绑华为SDK工具。

HarmonyOS公开完整源码，个人调试签名HAP仅用于绑定设备本地安装，不公开上传；其他设备需要在DevEco Studio中自行配置签名。源码、发行包和日志不包含私钥、口令或设备Profile。

## 已知限制

- 120／144为目标选项，不能承诺锁帧；平板实测系统激活120 Hz，解码提交帧率不等于面板扫描帧率。
- HDR会增加处理开销；HDR10不代表原生杜比视界，未实现原始杜比码流／RPU直通，也未完成真实杜比片源验收。
- 平板作为Mac系统摄像头仍在方案阶段，本版不包含采集或系统摄像头扩展。
- 未完成长期热稳定、全外观／旋转组合、特殊自绘光标及输入到光子的物理延迟测量。
