# 拇指分离键盘与玻璃调节面板 · V1.1.1

V1.1.1包含本轮键盘改进，V1.1.0标签与发行包保持不变。发布检查见[版本记录](RELEASE_1.1.1.md)。

## 布局与外观

- 字母排列遵循用户提供的分离输入法参考：左侧QWERT／ASDFG／ZXCV，右侧YUIOP／GHJKL／VBNM；中排向内错位，G／V重复，Mac功能键保持相对位置：Tab在Q左侧，Caps Lock在A左侧，Shift在Z左侧，fn／Control／Option／Command在左下角；Return在右侧主键行，删除在数字行右端，方向键在右下角为倒T形。双侧空格与Command可独立触摸。
- 数字与符号页保留相同几何，字母上标可长按输入；带修饰键时立即发送字母组合。ANSI／ISO／JIS额外键、F1–F20和方向／导航／媒体键由fn展开。默认分离键宽／高为56，尺寸独立存于`thumb-mac-v5`记录；旧的其他布局记录保留。
- 中间不再放语言切换或修饰键。输入法与中文／手写入口移至左上方紧凑控制胶囊；fn 在键盘上方展开功能键及导航键。
- 拖动胶囊左端握柄可上下移动分离／停靠键盘，悬浮布局还可左右移动。可在调节面板中精确改变离底高度，按布局和横竖屏保存位置，并按屏幕范围限制移动。
- 独立的左侧调节卡片替代满宽设置栏：键宽／键高并排，高度单列，键盘制式与触感设置紧凑排列。连接信息和其他选项收进“更多”，常态不显示 USB 状态横条。
- 键盘与调节卡片使用透明底色、局部背景模糊、渐变高光、细边缘和柔和阴影。模糊只用于面板，不为每个按键创建模糊层；按压保留缩放、下沉和颜色反馈，尊重减少动态效果设置。较小屏幕上的设置卡片可滚动。

## Delete 与 Caps Lock

- Delete／向前删除按下先删除一次，持续约 420 ms 后每 70 ms 重复；松手、移出／取消、禁用或组件离开均停止定时器。
- Mac 收到重复消息时发送完整的按下／松开事件，避免将独立消息标为实体键保持按下的系统重复事件。积压时继续丢弃多余重复消息，避免松手后补删。
- Caps Lock 短按在松手时切换 Mac 输入源，清除本虚拟键盘的大写锁定。长按约 350 ms 单独切换虚拟大写锁定，不同时切换输入源；再次长按可关闭。不会修改实体键盘的持久锁定状态。
- 保留单次修饰键、双击锁定、双手按住组合键、断线租期释放等原有逻辑。本轮未新增系统权限。

## 验证结果

- 双端签名构建与安装通过。Mac 固定签名身份未改变；正常重开后键盘通道恢复可用。
- 自动测试共 53 项通过，含直接加载实际 ArkTS 布局的 3 项测试（参考字母排列、页面身份、字符／Mac键覆盖）和实际按键生命周期的 4 项虚拟时钟测试及 1 项重复队列取消测试。原生修饰键租期／释放、PDF、白板、麦克风、光标、帧节奏和流格式回归通过。
- 真机 58 个常态按键、ANSI fn 展开后的 86 个按键均检查显示；常态和调节面板展开后，所有 58 个按键均在 2880 × 1920 屏幕范围内。
- 真机上下拖动、隐藏／恢复、重新安装后的位置记忆、离底高度滑杆、左侧输入法菜单均经过操作；调节卡片和圆角玻璃按键已截图检查。
- Mac 专用测试文本原有 62 个字符，平板持续按住 Delete 后剩 32 个，松手后停止删除。
- Caps Lock 短按实测输入源为 `ABC → 微信输入法 → ABC`；长按后 Caps 状态高亮，短按后取消高亮，长按未额外触发短按。
- 真实双指同时按住修饰键的手感、触感强度及更多第三方应用仍需手动补充验收；本轮验证了单指长按与真实 Mac 输入源切换，没有把自动化单指测试当作多指测试。

主要修改：`KeyboardLayout.ets`、`KeyboardPanel.ets`、`KeyboardKey.ets`、Mac `KeyboardHost.swift`、设计令牌与中英文文案，以及键盘布局／按压回归测试。截图与设备日志保留在仓库外的本地测试目录，不包含在发布资源中。
