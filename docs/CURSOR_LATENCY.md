# 高清拖动、鼠标延迟与沉浸式验证

2026-10-25完成主要真机验证，相关改动纳入2026-10-26的1.0.0。保持 2880 × 1920、原有高清码率与 HEVC 高帧率路径。

## 鼠标延迟

用户最终确认输入场景是鼠标连接 Mac，移动到平板扩展桌面。原路径把光标合成到 ScreenCaptureKit 视频帧中，指针需要等待整条视频链路；帧率高仍然会有跟手感问题。

- `macOS/LDCursorBridge.m`：单独的 USB 回环转发通道24836，读取系统光标形状、热点及位置；采样与发送使用最新快照，不排队旧位置。没有注入或改变鼠标输入。
- `HarmonyOS/entry/src/main/cpp/cursor_receiver.h`：后台接收、长度/范围校验、超时隐藏与形状缓存；原生最新位置邮箱供 UI 读取。
- `HarmonyOS/entry/src/main/ets/pages/CursorOverlay.ets`：小范围、不可命中的独立覆盖层，更新指针不重建控制面板，不等待解码器；坐标、尺寸和热点按虚拟显示器归一化，适配 HiDPI 和接收画面的黑边。
- 平板连接后才从视频中去掉光标；通道断开自动恢复视频光标。旧客户端未连接光标通道时保持原视频光标。短暂切换仍可能受下一帧更新时机影响。

用户在真机移动鼠标并拖动窗口后反馈“明显更跟手”。光标通道每120个样本的往返均值约4.8–5.9 ms；这只覆盖采样快照到平板原生接收确认，不包含 ArkUI 帧提交和屏幕扫描，不等于完整物理指针延迟。

移除24836转发规则时，日志确认 `CURSOR_MODE separated=0`；重建规则后恢复 `separated=1`。保留视频流、音频和麦克风原通道。

## 拖动时掉到约60 fps

人手拖动日志显示 Mac 采集仍约112–122 fps，编码/接收降到约56–76 fps，原始帧被大量替换。原45 ms软年龄阈值触发限流；编码约15–18 ms，平板接收后解码提交约18–23 ms，连同传输和确认回程经常超过该阈值。固定阈值会造成节奏振荡，低帧率也会增加相邻帧的变化量。

高帧率软阈值调整到70 ms，保留120目标最多5帧、144目标最多6帧的硬上限，保持原始帧新鲜度限制。60目标仍使用45 ms阈值。不丢弃已经编码的参考帧，也不通过降低分辨率或码率处理积压。

同一台设备再次人手拖动，用户反馈“帧率更高，拖动也跟手”。本次拖动窗口样本大多约114–131 fps，仍有一次约93 fps下探；采集到平板解码确认的120帧批次均值约43–45 ms，较此前拖动约57–66 ms改善。两段人手运动轨迹不同，这不是严格同轨迹或长期性能基准。144目标尚未持续达标。

最终版本在120目标的自动快速窗口移动短窗口里，逐秒解码提交帧率113–121，中位数118.5 fps，确认批次均值中位数38.3 ms。仍存在波动，不能称为锁120。144目标自动移动对比窗口中位数127.5 fps，同样不是锁144。

增加仅供调试的 `--strict-budget`、`--window-motion --fast-motion` 和 `--receipt-metrics`，用于复现旧阈值、重复窗口合成负载和区分整包接收确认与解码确认。自动窗口移动不能替代人手拖动验收。AVC高帧率试验不兼容本机低延迟编码配置，已撤回选择逻辑；未作为交付路径。

当前平板系统激活120 Hz，解码提交计数高于120不等于屏幕显示了相同数量的不同帧。系统虽报告支持144，应用144请求成功也不能视为屏幕已切到144。长期热稳定、实际扫描输出与输入到光子的延迟仍未测量。

## 底部白条

`PlatformUI.ets` 将沉浸式布局、手势指示条和普通系统栏设置分别执行并记录错误，防止前一个调用失败跳过手势指示条隐藏。真机截图确认扩展屏幕底部指示条消失；返回工作台恢复系统栏，再进入扩展屏幕再次隐藏。没有覆盖白条绘制假背景，也没有修改系统全局导航设置。

## 构建和证据

两端使用原签名身份覆盖安装，Mac通过正常应用启动测试。Mac、ArkTS/C++及签名HAP构建通过；统一回归37项、原生内存检查、麦克风同步、管线预算及帧节奏测试通过。新增光标通道回环测试覆盖分片TCP、确认、最新位置、图片缓存、过期隐藏、非法长度与退出；UI资源检查、空白检查及严格签名验证通过。仅有既有fabsf类型警告。

原始日志和截图位于本地仓库外 `../cursor-*.log`、`../window-drag-*.log`、`../floating-device-evidence/`。本轮仍需继续监测复杂高熵画面、大范围拖动、144 Hz实际输出、长时间运行，以及特殊应用隐藏/自绘光标。未将短窗口与主观反馈描述为长期锁帧或完整物理延迟保证。
