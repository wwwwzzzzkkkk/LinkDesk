# 扩展屏幕触摸控制（V1.2.0）

平板进入 USB 扩展屏幕后，可以在桌面画面上点按、双击、单指滑动滚动、单指拖动、停住长按（约 500 毫秒，右键）和双指滚动。快速滑动后以有上限的惯性减速；再次触摸、断线或退出时停止。若系统启用减少动态效果，则关闭惯性。悬浮面板与虚拟键盘仍由平板本地接收；需要平板键盘已有的配对与 Mac 输入授权。扩展屏幕本身目前仍使用 USB，不能声称无线副屏触摸已支持。

悬浮面板的“触摸·智能”会根据 Mac 控件及滑动方向判断滚动或拖动；点该按钮切换至“触摸·滚动”（强制滑动滚动）或“触摸·选字”（按住文字拖动选择），再点回智能。选择文字后可使用已有虚拟键盘的 Command+C 复制。部分应用未暴露控件类型时，智能模式按方向回退；如窗口拖动和滚动互相冲突，可切换模式。

平板在实际视频内容区域获取触点，映射到当前 Mac 虚拟显示器的逻辑坐标和位置，保留 HiDPI 与显示器排列。触摸使用独立持久连接及 AES-GCM、独立会话、序列和过期检查；按下／抬起按序发送，积压的移动取最新，滚动增量合并。断线、前后台切换、过期、输入授权失效和显示器消失时释放按住状态。视频编码、分辨率和 HDR 路径未改动。

## 设备验证

2026-10-29：Mac mini 与 MatePad 安装测试版，2880 × 1920 HDR10 画面正常。HDC 单指模拟中，按住并拖动 LinkDesk 测试窗口约 300 × 270 屏幕像素，窗口随手势移动相应距离，Mac 端确认按下及释放。用户在真机上反馈双指滚动、长按右键和触摸位置均正常；智能模式单指滚动可用，但初版反馈滑动有掉帧感。随后调整了滚动事件阶段、触点时间采样和惯性刷新节奏，用户复测反馈“明显更顺滑”，并确认文字选择和窗口拖动正常。仍需更多屏幕比例、方向、桌面排列、应用和长期使用验收；端到端物理延迟与长时间热稳定尚未测量，目标帧率并非保证值。

## macOS 原生触摸边界

Apple 的 2026 款 PROLED XDR MacBook Pro 和 macOS 27 已提供原生触摸，系统能将触摸转换为点击；AppKit 对应用提供触摸和手势接口。当前实现使用公开 Core Graphics 鼠标和滚动事件，不宣称第三方平板能注入系统级原生多点触摸。捏合缩放、压感、系统级多指手势和原生触屏专用应用行为尚未实现或验证。macOS 27 的手势接口面向应用接收触摸，不等同于公开的第三方系统级多点触摸注入接口。并不需要 ANE；触摸采样、配对、坐标转换和输入分发均为确定性路径。

## 虚拟键盘自动弹出

扩展屏幕中双击 Mac 的可编辑输入框后，Mac 通过辅助功能检查当前焦点和可写属性，并向平板发送加密、限时且防重放的提示，平板自动打开虚拟键盘。普通文字不会因双击而弹出；部分自绘输入框或未暴露可写属性的应用可能无法识别，可通过悬浮面板手动打开。安全输入或授权不可用时遵循原有状态与限制。键盘按钮在重连期间仍可打开面板并触发连接刷新，面板会显示实际连接状态。

2026-10-29 双端真机测试：用户确认普通输入框双击后键盘自动弹出且可以输入，悬浮键盘按钮可点。不同应用与安全输入框尚未全面验证。
