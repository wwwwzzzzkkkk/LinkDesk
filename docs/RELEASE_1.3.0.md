# LinkDesk V1.3.0

## 本次更新

- **双指扩展屏幕操作**：双指张开／捏合缩放，双指轻点右键；保留单指和双指滚动、长按右键、窗口拖动与选字。平板与 Mac 通过加密的独立触摸通道通信。
- **双端语音输入**：虚拟键盘按住“按住说话”，调用 Mac 输入法已启用的 Fn 语音快捷键；松开、失联、超时、键盘关闭或权限失效会释放按键。“中 / 英 → 平板输入法语音”可打开平板输入法，使用输入法话筒后确认发送文字到 Mac。
- **键盘收起与动画**：双击扩展桌面上可识别的空白处，或双手分离键盘中央留白，可收起键盘；双击受支持的 Mac 输入框仍可自动弹出。出现和消失加入淡入／位移，遵循减少动态效果。
- **悬浮面板精简**：麦克风改为可点击的状态图标，底部使用键盘、工作台、重连和隐藏图标；保留状态、实际帧率、屏幕刷新率、分辨率、触摸模式、拖动和收起恢复。移除“低延迟显示”开关界面，保留内部低延迟显示路径与不支持时的回退。
- **HDR 色彩**：新增 HDR 暗部原始／柔和／更深，以及原色／轻度鲜艳／更鲜艳。暗部调整仅作用于 HDR 画面，是可回退的观感调整而非 ICC 校色；默认原始，用户可自行调整。
- **鼠标流畅度**：独立光标的位置采样从主界面线程移至独立队列，减少主线程忙碌时的干扰；保持最新位置优先、有限在途和断线回退。

## 真机验证

- 用户确认网页和 PDF 双指缩放、双指滚动与轻点右键正常。分离键盘中间留白通过 HDC 双击测试；用户确认桌面空白双击收起、输入框自动弹出及出现动画自然。
- 用户确认 Mac 微信输入法语音界面能够唤起且文字正确输入，平板输入法语音识别文字经确认后正确发送。平板语音入口移动到菜单后，重新验证了输入法编辑区可打开。
- HDR 用户对比反馈 SDR 暗部更黑；HDR “更深”档更接近 ViewSonic、暗部细节正常，与“轻度鲜艳”同时使用正常，拖动没有明显变卡。10-bit PQ 灰阶测试验证纯黑不变、暗灰降低、测试白点与高光保持不变。
- 用户确认光标优化版启动后移动和拖动更流畅。目标 144 fps 时平板实际报告 120 Hz；部分一秒 HDR 样本约 60–117 fps，画面与负载未严格控制，不能宣称锁帧或给出长期性能结论。
- 双端构建、61 项协议及键盘测试、原生回归、色彩灰阶测试和界面检查通过。Mac 保持原签名身份，平板使用原个人调试签名安装验证。

## 已知限制与安装

- 缩放使用 macOS 未公开的合成事件格式，可能受系统升级或应用实现影响；并非完整系统级原生多点触摸。三指及更多手指系统手势、触控压感未实现。
- Mac 语音入口依赖输入法实际支持并启用 Fn 语音快捷键；其他快捷键或输入法未全面验证。平板语音需要自行点击输入法的话筒；识别服务及权限由所选输入法负责。
- 有些 Mac 应用未暴露准确的无障碍角色，双击空白收起或输入框识别可能失效，可使用面板按钮。收起动画、所有应用及连续断网尚未全面验收。
- HDR 暗部调节不会改变真实纯黑时的硬件黑位；过强会降低暗部细节。滤镜使用已弃用的 Core Image 文本着色器接口，未来系统兼容性需要继续检查；处理不可用时回退原画面。
- 当前硬件链路只验证到 10-bit HDR10；没有真实 12-bit 支持，也不支持杜比视界原始码流及动态元数据直通。尚无仪器级色彩校准、端到端光学延迟或长期热稳定结果。
- 公开发行包括 Apple Silicon Mac 安装包和双端源码；鸿蒙个人调试签名绑定设备，需自行在 DevEco Studio 配置签名。Mac 包使用固定开发证书，尚未经过 Apple Developer ID 公证。
