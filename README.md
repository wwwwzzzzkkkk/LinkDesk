# LinkDesk

Mac 与 MatePad 的跨屏工作空间。**V1.1.0** 新增可调尺寸的 Mac 虚拟键盘，将高清扩展屏幕、低延迟独立光标、HDR10、双向音频、PDF 批注、无限白板、平板投屏和华为笔记往返放进同一个 LinkDesk。平板可通过 USB 或 Wi-Fi 为 Mac 输入，优先适配全宽停靠与双手分离。

[下载 V1.1.0](https://github.com/wwwwzzzzkkkk/LinkDesk/releases/tag/v1.1.0) · [更新记录](CHANGELOG.md) · [安装说明](docs/INSTALL.md) · [本版验证与限制](docs/RELEASE_1.1.0.md)

| 工作空间 | 用途 | 连接 |
| --- | --- | --- |
| 扩展屏幕 | 把平板用作独立桌面，并连接扬声器与麦克风 | USB |
| PDF 批注 | 两端同步阅读、压感书写、撤销与导出 | USB / Wi-Fi |
| 实时白板 | 无限画布、双向缩放和平移、独立历史 | USB / Wi-Fi |
| 平板投屏 | 把平板全屏画面投射到 Mac | USB |

Mac 使用原生侧栏；平板使用统一工作台和悬浮书写工具栏。两端提供同步的“跟随系统／浅色／深色”外观选择，自动模式跟随 Mac。应用名称、图标与功能顺序一致，视觉采用蓝色、薄荷绿与原生材质。双端令牌、截图与验收范围见 [UI 一致性](docs/ui-parity/README.md)。完整架构、兼容规则与验收记录见 [整合说明](docs/UNIFICATION.md)。

## V1.1.0 功能与特点

### 平板上的 Mac 虚拟键盘 · V1.1.0 新增

- **全宽停靠与双手分离**：完整英文数字与标点键，分离模式左右贴边并各有空格；还提供大按键全屏模式和可拖动的紧凑悬浮模式。
- **尺寸自己调**：键宽、键高可调，按布局及横竖屏分别记忆，宽度上限随可用空间和数字区自动适配。按下立即变色并轻微缩小、下沉，减少动态效果时保留颜色；设备支持时可开启触感反馈。
- **Mac 按键与组合键**：Command／Option／Control／Shift 可点按供下一键使用、双手按住组合或双击锁定；支持 Esc、F1–F20、前后删除、导航、方向键、数字区及 ANSI／ISO／JIS 手动布局。fn展开功能区；Caps短按遵循Mac设置，长按或“⇪ ABC”可锁定本键盘的大写输入。
- **USB／Wi-Fi 都能输入**：连接与画面通道分开，顶部显示实际键盘通道，可选择优先方式。Mac当前前台应用接收按键；中文、手写及表情可用平板系统输入法确认后发送。
- **通知栏入口**：连接就绪后，可从平板下拉通知栏点击“虚拟键盘”回到 LinkDesk 输入；这是通知入口，会打开应用，尚不是系统控制中心快捷开关或跨应用悬浮窗。
- **认证与状态释放**：独立随机配对密钥、加密输入与确认、递增序号及过期拒绝；收起／后台清理待发输入，持续修饰键丢失续租约1.5秒后释放，避免跨重连补打。

Mac首次需允许LinkDesk发送按键：本机macOS 27入口为“隐私与安全 → 设备控制和数据访问”，旧版为“辅助功能”。两端需要一起更新，旧六位房间号本身不授予键盘控制权限。双手同时触摸、长时间连发节奏及触感的主观验收仍待补充，不宣称已验证所有应用或自定义键位。详见[虚拟键盘使用与验证](docs/VIRTUAL_KEYBOARD.md)。

### 高清扩展屏幕与更跟手的鼠标

- **独立扩展桌面**：通过 USB 将 MatePad 作为 Mac 的第二块屏幕，保持 2880 × 1920 画面；可在 Mac 系统设置中排列显示器，并在应用中选择显示缩放和 60／120／144 fps 目标。
- **独立光标通道**：鼠标连接 Mac、移动到平板扩展桌面时，位置与形状单独传输；移动指针无需等待桌面视频的编码与解码。通道断开时自动回退到视频内光标。
- **高清拖动优化**：保留分辨率和既有高清码率，通过新鲜帧优先、有限在途帧及硬件编码改善拖动窗口时的帧节奏，避免持续堆积旧画面。
- **沉浸显示**：扩展屏幕隐藏系统栏与底部手势白条；返回工作台恢复系统界面。

### 紧凑玻璃悬浮面板

平板扩展桌面上持续显示可拖动的紧凑控制面板，提供帧率／连接状态、麦克风状态、返回工作台、重新连接与隐藏。面板位于视频内容之上且可以交互；隐藏采用弹簧过渡，并保留小胶囊用于恢复。独立光标更新不重建整个面板，减少不必要的界面刷新。

面板中的解码帧率用于观察传输表现，不能等同于屏幕实际扫描刷新率。系统报告的刷新率与目标帧率也不是持续达标保证。

### HDR10 与广色域

Mac 扩展屏幕设置提供 **HDR10 · 10-bit** 开关，默认关闭。启用后，两端协商能力，使用真实 HDR 采集、HEVC Main10、BT.2020／PQ 传输及平板10-bit显示缓冲验证；重新连接后生效。HDR 虚拟屏使用 P3 色域，最终亮度和色域由平板显示系统映射。

HDR 路径需要 macOS 15+、Apple Silicon 和兼容的平板显示／解码能力；运行时检查不通过会禁用或提示失败。**当前不支持原生杜比视界码流及 RPU 动态元数据直通**，也未完成真实杜比片源验收。具体链路与真机证据见 [HDR 支持说明](docs/HDR_SUPPORT.md)。

### 扬声器与麦克风协同

- 将 Mac 声音通过 USB 发送至平板扬声器，也可选择 Mac 与 MatePad 同时播放。
- 将平板麦克风作为 Mac 音频输入；在 **Mac 或平板任意一端**启用／关闭，另一端自动同步，无需重复选择。
- Mac 系统输入切换到平板麦克风时也会联动；关闭后恢复已记录的物理输入设备。
- 平板首次使用需要录音授权；离开前台、退出副屏或拒绝授权会停止拾音并同步状态。画质／帧率设置引起的重连保留原麦克风开启意图。

### PDF 批注、白板与投屏

- **PDF 批注**：两端同步阅读和书写，支持压感、手指平移、双指缩放、撤销／重做；Mac 支持文字选择、⌘F 搜索和另存为标准 PDF Ink 批注。
- **无限白板**：25%–800% 缩放、双向视口同步、独立历史、撤销／重做及持久化。
- **华为笔记往返**：Mac 发送 PDF 到平板，优先打开华为笔记；完成后通过分享回传，Mac 保存批注副本。
- **平板投屏**：经平板系统授权后将全屏画面投射至 Mac；进入扩展屏幕前自动停止投屏，避免资源冲突。
- **连接与配对**：PDF／白板可扫码或使用相同六位房间号，优先 USB，断线回退 Wi-Fi；外观设置在两端同步并持久化。

### 实测表现与支持边界

以下为V1.0.0阶段的 Mac mini 与 MatePad 短窗口样本，V1.1.0未重做这些性能基准，画面保持 2880 × 1920。负载、温度和系统刷新策略都会影响结果。

| 模式 | 实测样本 | 说明 |
| --- | --- | --- |
| SDR，目标120 fps | 113–121 fps，中位数118.5 | 快速窗口运动测试，仍有波动 |
| SDR，目标144 fps | 中位数127.5 fps | 尚未持续达到144 |
| HDR，目标60 fps | 约57–61 fps | HDR有额外处理开销 |
| HDR，目标120 fps | 约86–90 fps | 尚未锁120 |
| HDR，目标144 fps | 稳定段约75–79 fps | 仍有更低波动 |

人手拖动时，用户反馈独立光标“明显更跟手”，高清防积压优化后“帧率更高，拖动也跟手”。这些反馈不是完整物理延迟测量。当前平板系统激活120 Hz，解码提交超过120 fps不代表屏幕显示了同样数量的不同帧；未完成长期热稳定及输入到光子的延迟测量。详见 [光标与拖动验证](docs/CURSOR_LATENCY.md)。

平板作为 Mac 系统摄像头的功能仍在方案阶段，**V1.1.0 不包含该功能**。HDR10不代表原生杜比视界支持。

## 构建与安装

Mac：Apple Silicon、macOS 14+；构建使用 Swift 6 和支持 macOS 26 SDK 的 Xcode。构建脚本下载并校验官方 Node 24.14.1 便携运行时，随应用打包；使用者无需单独安装 Node。华为 HDC SDK 工具不进入公开安装包。

```sh
LINKDESK_SIGN_IDENTITY="固定代码签名证书名称或指纹" LINKDESK_BUNDLE_HDC=0 bash scripts/build-mac.sh
bash scripts/install-mac.sh ../LinkDesk.app
```

使用同一证书更新，保留 `com.zhekuan.linkdesk.mac` 和录屏权限身份。安装器会备份旧应用并拒绝不兼容签名。不要手动覆盖或重新签名已安装应用。无证书时可用 `LINKDESK_SIGN_IDENTITY=-` 生成开发测试包，不能覆盖已授权版本。

USB 工具会依次尝试应用内工具、本机 `~/Library/Application Support/LinkDesk/tools/hdc` 和 DevEco Studio SDK。HDC 与其 libusb 库需要配套。可用 `LINKDESK_HDC` 指定平板安装工具路径。

鸿蒙：DevEco Studio 打开 `HarmonyOS/`，保持 `com.zhekuan.linkdesk`，在本机配置自动调试签名后构建。源码不包含签名材料。也可在独立本机构建目录保留私有签名，通过 `LINKDESK_HARMONY_BUILD_ROOT` 指定该目录。

```sh
bash scripts/build-harmony.sh
bash scripts/install-harmony.sh
```

安装器使用覆盖安装，不删除应用数据。首次配置平板时，开启开发者选项和 USB 调试并允许 Mac。签名证书过期时先在 DevEco 更新，不能通过卸载应用绕过更新失败。

## 使用

- 两端打开 LinkDesk，在工作台选择工作空间。PDF／白板通过“连接与配对”扫码或使用同一个六位房间号；自动连接优先 USB，断线回退 Wi-Fi。
- 扩展屏幕：平板选择“扩展屏幕”，Mac 允许录屏；在 Mac“排列显示器”调整位置。
- 虚拟键盘：连接就绪后，在扩展屏幕悬浮面板或工作台打开“键盘”；选择全宽／分离／全屏／悬浮，在“调节”中设置尺寸。Mac先点选接收输入的应用与文本框。
- PDF：Mac 打开 PDF，平板手写；手指平移、双指缩放。Mac 支持文字选择、⌘F 搜索、撤销／重做和另存为标准 PDF Ink 批注。
- 白板：两端切换“实时白板”，画布没有边界，缩放范围 25%–800%。
- 华为笔记：文件菜单“发送 PDF 到平板批注…”，平板优先打开华为笔记；完成后通过分享菜单回传 LinkDesk，Mac 保存批注副本。
- 平板投屏：保持 USB 连接，在任一端启动并在平板允许系统录屏。进入平板扩展屏幕前会停止平板投屏。
- 麦克风每次默认关闭；在平板或 Mac 任一端启用即通过 USB 同步，Mac 声音设置切换到平板输入也会启用。平板首次使用仍需授予系统录音权限；拒绝授权、离开前台或退出副屏会停止拾音并同步关闭。麦克风双向同步需要两端均更新到此实现。

首次使用扬声器或麦克风，需要已有 LinkDesk Core Audio 驱动；驱动无需因本次 UI／工作区合并而重新安装。驱动安装会请求管理员授权并短暂重启音频服务，见 [安装说明](docs/INSTALL.md)。

## 验证

```sh
cd InkBridge && npm ci --ignore-scripts && npm test
```

协议还覆盖键盘认证、加密确认、按键白名单、序号、有效期和修饰键续租。协议覆盖 PDF 生命周期、断线快照、压感、视口控制、白板历史、撤销与重做、持久化和双向投屏控制。`scripts/check-unified.sh` 还会编译并运行 PDF 坐标、白板像素、麦克风与修饰键释放回归。界面开发可通过 `--ui-snapshots /absolute/output/directory` 仅渲染应用自己的内容视图；测试房间请用 `-InkBridgeRoomCode QA2026`，避免写入日常文档房间。
