# LinkDesk

Mac 与 MatePad 的跨屏工作空间。**V1.4.0** 增加扩展屏幕手写笔识别与压感，并支持与手指一致的智能滚动、选字及双击键盘操作；优化手写笔采样传输及高清画面流畅度。平板可通过 USB 或 Wi-Fi 为 Mac 输入；同一应用还提供 2880 × 1920 扩展屏幕、独立光标、HDR10、双向音频、PDF 批注、无限白板、平板投屏和华为笔记往返。

[下载 V1.4.0](https://github.com/wwwwzzzzkkkk/LinkDesk/releases/tag/v1.4.0) · [更新记录](CHANGELOG.md) · [安装说明](docs/INSTALL.md) · [本版验证与限制](docs/RELEASE_1.4.0.md)

| 工作空间 | 用途 | 连接 |
| --- | --- | --- |
| 扩展屏幕 | 把平板用作独立桌面，并连接扬声器与麦克风 | USB |
| PDF 批注 | 两端同步阅读、压感书写、撤销与导出 | USB / Wi-Fi |
| 实时白板 | 无限画布、双向缩放和平移、独立历史 | USB / Wi-Fi |
| 平板投屏 | 把平板全屏画面投射到 Mac | USB |

Mac 使用原生侧栏；平板使用统一工作台和悬浮书写工具栏。两端提供同步的“跟随系统／浅色／深色”外观选择，自动模式跟随 Mac。应用名称、图标与功能顺序一致，视觉采用蓝色、薄荷绿与原生材质。双端令牌、截图与验收范围见 [UI 一致性](docs/ui-parity/README.md)。完整架构、兼容规则与验收记录见 [整合说明](docs/UNIFICATION.md)。

## V1.4.0 功能与特点

### 扩展屏幕手写笔与流畅度 · V1.4.0

- **手写笔与压感**：区分手指与手写笔，传递笔尖坐标、压力和倾斜；Mac 发送带压力的数位笔点及进入／离开事件。用户在测试画布和 macOS 无边记中确认轻重可改变笔迹粗细。
- **手写笔智能触摸**：笔可像手指一样滚动网页、拖动、长按右键、切换选字模式，并双击受支持输入框或空白处控制虚拟键盘；真实应用角色识别不完整时可切换触摸模式。
- **采样与画面流畅度**：手写笔历史点按帧批量加密传输，保留有限的轨迹及压力数据，避免每个采样点单独发包；高清 HEVC 采集增加缓冲，保留 2880 × 1920 HDR10 和低延迟策略。用户反馈手指和笔滑动流畅、书写压感正常。实际帧率和端到端延迟随设备、内容及系统负载变化。
- 需要双端一起更新。手写笔接触期间忽略手指，以减少误触；笔与手指同时构成双指手势暂不支持。其他绘画应用和设备需分别验证；详见[本版发布记录](docs/RELEASE_1.4.0.md)。

### 多指、语音与画面改进 · V1.3.0

- **双指操作**：扩展屏幕双指张开／捏合缩放、双指滚动、双指轻点右键；用户在网页和 PDF 真机确认可用。捏合发送模拟 macOS 缩放手势，使用未公开事件格式，系统更新或个别应用可能不兼容；不等同于原生多点触摸注入；三指手势暂不支持。
- **双端语音**：虚拟键盘按住“按住说话”调用 Mac 输入法的 Fn 语音快捷键，松手结束；“中 / 英 → 平板输入法语音”可使用平板输入法，识别后确认发送。Mac 微信输入法和平板输入法均经用户真机验证；Mac 输入法需要启用 Fn 语音快捷键，平板方式需在输入法里点话筒。
- **键盘与悬浮面板**：双击扩展桌面可识别空白处或分离键盘中央空隙收起键盘，双击受支持输入框自动展开；出现／消失使用动画。悬浮面板以麦克风状态图标和四个操作图标替代整行文字，保留触摸模式、帧率、HDR 和拖动收起。
- **HDR 色彩**：Mac 可选 HDR 暗部原始／柔和／更深及原色／轻度鲜艳／更鲜艳；HDR 暗部采用低亮度调节，不是显示器 ICC 校色。用户反馈更深档与轻度鲜艳组合更接近 ViewSonic 且细节正常。
- **光标流畅度**：位置采样改为独立队列，降低主界面忙碌时的抖动；用户反馈重连后移动和拖动更流畅。实际帧率仍随画面波动，启动期与长期热稳定未完全解决。
- 详细使用、测试与已知限制见[本版发布记录](docs/RELEASE_1.3.0.md)。

### 触摸与候选词 · V1.2.0

- USB 扩展屏幕支持点按、双击、拖动、长按右键、单指／双指滚动、惯性减速和文字选择，提供智能／滚动／选字模式。
- 双击可识别的 Mac 输入框自动弹出虚拟键盘；重连期间键盘按钮仍可打开并刷新状态。
- Mac 微信输入法的候选词同步显示在键盘上方，支持点击选词；候选原位更新，短暂空结果不立刻收起。其他输入法及单候选场景尚未保证支持。
- 保持 2880 × 1920、HDR10 与独立光标；触摸使用鼠标、滚动及模拟缩放手势；当时不支持原生多点触摸与扩展屏幕压感；压感于 V1.4.0 加入。
- 真机用户确认触摸、选字、键盘自动弹出及微信候选选词可用；滚动与候选更新反馈自然。详见[触摸说明](docs/TOUCH_CONTROL.md)及[1.2.0 验证](docs/RELEASE_1.2.0.md)。

### 平板光感与输入稳定性 · V1.1.2

- **统一沉浸光感视觉**：目标 HarmonyOS API 26；系统支持的菜单、滑块、开关使用原生光感，其余自绘面板、键盘与视频浮层使用协调的轻量玻璃视觉。最低兼容 API 24，低版本采用降级样式。
- **页面更稳定**：统一工作台和书写界面的安全区域，避免切换功能时整体上下跳动；扩展屏幕在画面就绪后进入沉浸模式，退出时恢复系统栏。
- **快速光标更流畅**：独立光标使用有限在途窗口和最新位置优先，避免过期坐标堆积；用户实机反馈快速移动比之前好很多。
- **改善帧节奏**：限制迟到回调造成的追赶突发，保留 2880 × 1920 和原有画质；实测帧率仍随负载波动，不能承诺稳定 120／144 fps。详见[光标与帧节奏](docs/CURSOR_FRAME_STABILITY.md)及[平板视觉](docs/IMMERSIVE_LIGHT_UI.md)。

### 平板上的 Mac 虚拟键盘 · V1.1.1 改进

- **适合拇指的分离字母区**：左侧 QWERT／ASDFG／ZXCV，右侧 YUIOP／GHJKL／VBNM；中排向内错位，G、V 两侧重复。Tab位于Q左侧、Caps Lock位于A左侧、Shift位于Z左侧，fn／Control／Option／Command在左下角；Return在右侧主键行、删除在数字行右端，方向键在右下角呈倒T形。左右均有空格与Command；另有全宽停靠、大按键全屏、紧凑悬浮形态。
- **数字、符号与完整 Mac 按键**：分离模式顶端保留数字行，左侧“符号”菜单切换字母／数字／符号页；字母上标可长按输入。fn 展开 Esc、F1–F20、导航、方向与媒体键，支持前后删除、数字区和 ANSI／ISO／JIS 额外键。Command／Option／Control／Shift 支持点按一次、按住组合或双击锁定；带修饰键的字母立即发送组合，不触发上标。
- **液态玻璃与紧凑调节**：透明底色、局部背景模糊、圆角键帽、细高光和柔和阴影；左侧独立调节卡片提供键宽、键高、离底高度、键盘制式及触感反馈。输入法入口在左侧小胶囊中，中央留白，常态不显示整条连接状态栏。
- **尺寸与位置记忆**：停靠／分离键盘可上下拖动，紧凑悬浮还可左右移动；尺寸、位置按布局和横竖屏分别保存，自动限制屏幕边界。按下立即变色并轻微缩小、下沉，减少动态效果时保留颜色；模糊仅用于面板，避免为每颗按键创建模糊层。
- **Delete 与 Caps Lock 修复**：Delete 持续按住约420毫秒后，每70毫秒重复删除；松手取消待发送的重复删除，减少延迟补删。Caps Lock 短按切换 Mac 输入源，长按单独切换本虚拟键盘的大写锁定，不同时触发短按。
- **USB／Wi-Fi 都能输入**：键盘连接独立于视频，Mac 当前前台应用接收按键；“调节 → 更多选项”查看实际通道并选择优先方式。中文、手写及表情可通过左侧“中 / 英 → 中文 / 手写”调用平板输入法，确认后发送。
- **通知栏入口**：连接就绪后，可从平板下拉通知栏点击“虚拟键盘”回到 LinkDesk 输入；这是通知入口，会打开应用，尚不是系统控制中心快捷开关或跨应用悬浮窗。
- **认证与状态释放**：独立随机配对密钥、加密输入与确认、递增序号及过期拒绝；收起／后台清理待发输入，持续修饰键丢失续租约1.5秒后释放，避免跨重连补打。

Mac 首次需允许 LinkDesk 发送按键：本机 macOS 27 入口为“隐私与安全 → 设备控制和数据访问”，旧版为“辅助功能”。**使用本版功能需两端一起升级到 V1.4.0**，以使用完整的 Caps Lock 与重复删除修复。旧六位房间号本身不授予键盘控制权限。

本轮真机长按 Delete 连续删去30个字符，Caps Lock 实测 ABC → 微信输入法 → ABC；53项自动测试及原生回归通过。真实双指同时按住的手感、触感强度和所有应用／自定义键位兼容性尚未穷尽验收。详见[虚拟键盘使用与验证](docs/VIRTUAL_KEYBOARD.md)、[布局与调节说明](docs/KEYBOARD_MAC_SPLIT.md)。

### 高清扩展屏幕与更跟手的鼠标

- **独立扩展桌面**：通过 USB 将 MatePad 作为 Mac 的第二块屏幕，保持 2880 × 1920 画面；可在 Mac 系统设置中排列显示器，并在应用中选择显示缩放和 60／120／144 fps 目标。
- **独立光标通道**：鼠标连接 Mac、移动到平板扩展桌面时，位置与形状单独传输；移动指针无需等待桌面视频的编码与解码。通道断开时自动回退到视频内光标。
- **高清拖动优化**：保留分辨率和既有高清码率，通过新鲜帧优先、有限在途帧及硬件编码改善拖动窗口时的帧节奏，避免持续堆积旧画面。
- **沉浸显示**：扩展屏幕隐藏系统栏与底部手势白条；返回工作台恢复系统界面。

### 扩展屏幕触摸控制 · V1.2.0

连接后的平板扩展桌面支持直接点按、双击、单指／双指滚动、双指缩放、双指轻点右键、单指拖动、长按右键和文字选择，保留高清画面及独立光标；需要现有平板配对和 Mac 输入授权。使用方法、实机验证与原生触摸边界见[触摸控制说明](docs/TOUCH_CONTROL.md)。

### 紧凑玻璃悬浮面板

平板扩展桌面上持续显示可拖动的紧凑控制面板，提供帧率／连接状态、麦克风状态、返回工作台、重新连接与隐藏。面板位于视频内容之上且可以交互；隐藏采用弹簧过渡，并保留小胶囊用于恢复。独立光标更新不重建整个面板，减少不必要的界面刷新。

面板中的解码帧率用于观察传输表现，不能等同于屏幕实际扫描刷新率。系统报告的刷新率与目标帧率也不是持续达标保证。

### HDR10 与广色域

Mac 扩展屏幕设置提供 **HDR10 · 10-bit** 开关，默认关闭。启用后，两端协商能力，使用真实 HDR 采集、HEVC Main10、BT.2020／PQ 传输及平板10-bit显示缓冲验证；重新连接后生效。HDR 虚拟屏使用 P3 色域，最终亮度和色域由平板显示系统映射。

HDR 路径需要 macOS 15+、Apple Silicon 和兼容的平板显示／解码能力；运行时检查不通过会禁用或提示失败。**当前不支持原生杜比视界码流及 RPU 动态元数据直通**，也未完成真实杜比片源验收。具体链路与真机证据见 [HDR 支持说明](docs/HDR_SUPPORT.md)。

### 扬声器与麦克风协同

- 将 Mac 声音通过 USB 发送至平板扬声器，也可选择 Mac 与 MatePad 同时播放。
- 将平板麦克风作为 Mac 音频输入；在 **Mac 或平板任意一端**启用／关闭，另一端自动同步，无需重复选择。
- Mac 系统输入切换到平板麦克风时也会联动；关闭后恢复已记录的物理输入设备。
- 平板首次使用需要录音授权；离开前台、退出副屏或拒绝授权会停止拾音并同步状态。画质／帧率设置引起的重连保留原麦克风开启意图。

### PDF 批注、白板与投屏

- **PDF 批注**：两端同步阅读和书写，支持压感、手指平移、双指缩放、撤销／重做；Mac 支持文字选择、⌘F 搜索和另存为标准 PDF Ink 批注。
- **无限白板**：25%–800% 缩放、双向视口同步、独立历史、撤销／重做及持久化。
- **华为笔记往返**：Mac 发送 PDF 到平板，优先打开华为笔记；完成后通过分享回传，Mac 保存批注副本。
- **平板投屏**：经平板系统授权后将全屏画面投射至 Mac；进入扩展屏幕前自动停止投屏，避免资源冲突。
- **连接与配对**：PDF／白板可扫码或使用相同六位房间号，优先 USB，断线回退 Wi-Fi；外观设置在两端同步并持久化。

### 实测表现与支持边界

以下为V1.0.0阶段的 Mac mini 与 MatePad 短窗口样本，V1.1.1未重做这些性能基准，画面保持 2880 × 1920。负载、温度和系统刷新策略都会影响结果。

| 模式 | 实测样本 | 说明 |
| --- | --- | --- |
| SDR，目标120 fps | 113–121 fps，中位数118.5 | 快速窗口运动测试，仍有波动 |
| SDR，目标144 fps | 中位数127.5 fps | 尚未持续达到144 |
| HDR，目标60 fps | 约57–61 fps | HDR有额外处理开销 |
| HDR，目标120 fps | 约86–90 fps | 尚未锁120 |
| HDR，目标144 fps | 稳定段约75–79 fps | 仍有更低波动 |

人手拖动时，用户反馈独立光标“明显更跟手”，高清防积压优化后“帧率更高，拖动也跟手”。这些反馈不是完整物理延迟测量。当前平板系统激活120 Hz，解码提交超过120 fps不代表屏幕显示了同样数量的不同帧；未完成长期热稳定及输入到光子的延迟测量。详见 [光标与拖动验证](docs/CURSOR_LATENCY.md)。

平板作为 Mac 系统摄像头的功能仍在方案阶段，**V1.4.0 不包含该功能**。HDR10不代表原生杜比视界支持。

## 构建与安装

Mac：Apple Silicon、macOS 14+；构建使用 Swift 6 和支持 macOS 26 SDK 的 Xcode。构建脚本下载并校验官方 Node 24.14.1 便携运行时，随应用打包；使用者无需单独安装 Node。华为 HDC SDK 工具不进入公开安装包。

```sh
LINKDESK_SIGN_IDENTITY="固定代码签名证书名称或指纹" LINKDESK_BUNDLE_HDC=0 bash scripts/build-mac.sh
bash scripts/install-mac.sh ../LinkDesk.app
```

使用同一证书更新，保留 `com.zhekuan.linkdesk.mac` 和录屏权限身份。安装器会备份旧应用并拒绝不兼容签名。不要手动覆盖或重新签名已安装应用。无证书时可用 `LINKDESK_SIGN_IDENTITY=-` 生成开发测试包，不能覆盖已授权版本。

USB 工具会依次尝试应用内工具、本机 `~/Library/Application Support/LinkDesk/tools/hdc` 和 DevEco Studio SDK。HDC 与其 libusb 库需要配套。可用 `LINKDESK_HDC` 指定平板安装工具路径。

鸿蒙：DevEco Studio 打开 `HarmonyOS/`，保持 `com.zhekuan.linkdesk`，在本机配置自动调试签名后构建。源码不包含签名材料。也可在独立本机构建目录保留私有签名，通过 `LINKDESK_HARMONY_BUILD_ROOT` 指定该目录。

```sh
bash scripts/build-harmony.sh
bash scripts/install-harmony.sh
```

安装器使用覆盖安装，不删除应用数据。首次配置平板时，开启开发者选项和 USB 调试并允许 Mac。签名证书过期时先在 DevEco 更新，不能通过卸载应用绕过更新失败。

## 使用

- 两端打开 LinkDesk，在工作台选择工作空间。PDF／白板通过“连接与配对”扫码或使用同一个六位房间号；自动连接优先 USB，断线回退 Wi-Fi。
- 扩展屏幕：平板选择“扩展屏幕”，Mac 允许录屏；在 Mac“排列显示器”调整位置。
- 虚拟键盘：连接就绪后，在扩展屏幕悬浮面板或工作台打开“键盘”；选择全宽／分离／全屏／悬浮，在“调节”中设置尺寸和离底高度，拖动左侧握柄移动键盘。Mac先点选接收输入的应用与文本框。
- PDF：Mac 打开 PDF，平板手写；手指平移、双指缩放。Mac 支持文字选择、⌘F 搜索、撤销／重做和另存为标准 PDF Ink 批注。
- 白板：两端切换“实时白板”，画布没有边界，缩放范围 25%–800%。
- 华为笔记：文件菜单“发送 PDF 到平板批注…”，平板优先打开华为笔记；完成后通过分享菜单回传 LinkDesk，Mac 保存批注副本。
- 平板投屏：保持 USB 连接，在任一端启动并在平板允许系统录屏。进入平板扩展屏幕前会停止平板投屏。
- 麦克风每次默认关闭；在平板或 Mac 任一端启用即通过 USB 同步，Mac 声音设置切换到平板输入也会启用。平板首次使用仍需授予系统录音权限；拒绝授权、离开前台或退出副屏会停止拾音并同步关闭。麦克风双向同步需要两端均更新到此实现。

首次使用扬声器或麦克风，需要已有 LinkDesk Core Audio 驱动；驱动无需因本次 UI／工作区合并而重新安装。驱动安装会请求管理员授权并短暂重启音频服务，见 [安装说明](docs/INSTALL.md)。

## 验证

```sh
cd InkBridge && npm ci --ignore-scripts && npm test
```

协议还覆盖键盘认证、加密确认、按键白名单、序号、有效期和修饰键续租。协议覆盖 PDF 生命周期、断线快照、压感、视口控制、白板历史、撤销与重做、持久化和双向投屏控制。`scripts/check-unified.sh` 还会编译并运行 PDF 坐标、白板像素、麦克风与修饰键释放回归。界面开发可通过 `--ui-snapshots /absolute/output/directory` 仅渲染应用自己的内容视图；测试房间请用 `-InkBridgeRoomCode QA2026`，避免写入日常文档房间。
