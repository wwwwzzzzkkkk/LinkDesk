# 图标

`linkdesk-icon.png` 是原始生成图，`LinkDesk.icns` 用于 macOS，HarmonyOS 使用同图 PNG。图标为蓝紫底色上的青色与白色相连屏幕轮廓。

通过内置 imagegen 工具生成，未使用 CLI/API。提示词：

> Create a finished macOS app icon for LinkDesk, a USB extended display app connecting a Mac and tablet with audio. Single square icon, centered large two interlocking rounded rectangular display outlines forming an elegant chain link, one luminous cyan and one soft white, subtle blue indigo gradient rounded-square tile with restrained depth and polished glass edges. Bold simple silhouette readable at 32px. No text, no letters, no cables, no extra symbols, no mockup, no surrounding scene. Icon tile fills image, 1024x1024.
